# Python Programs Collection

Small Python scripts for common programming tasks and demos.

| File | Description |
|------|-------------|
| `factorial.py` | Computes the factorial of a user-entered number |
| `fibonacci.py` | Prints the first *n* Fibonacci numbers |
| `structure_to_dict.py` | Demonstrates converting tuples, lists, and objects to dicts |

## Technology

Python 3

## How to run

```bash
python filename.py
```

Replace `filename.py` with the script you want to run (e.g. `python factorial.py`).
